## What it does

`main.ts` (Node 22+) writes one funny single-line one-star review, written by a house cat about its human, to `/output/entry.txt`:

> One star. The food arrives late, the human sleeps on MY side of the bed, and he has the nerve to call my 3 a.m. zoomies 'a problem.'

The line is 132 characters — under the 200-character limit — and a single line.

## Run it

```sh
node main.ts
```

It validates the entry (non-blank, at most 200 characters, single line) and writes it to `/output/entry.txt`.
